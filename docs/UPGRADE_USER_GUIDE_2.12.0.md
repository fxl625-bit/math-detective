# 数学侦探 2.12：使用与恢复

本次范围是一至六年级的通用数学能力训练，每个年级提供六个学习单元。孩子目前所在年级只决定初始选择；各年级采用同一质量标准。单元不对应某一出版社的整册教材，也不宣称已经覆盖全部教材知识点。

## 开始学习

1. 首页打开“设置”，选择年级、当前单元与学期。自动学期可以手动覆盖；单元目录是通用能力目录。
2. 二年级乘除单元可填写已经学过的口诀范围；尚未确定时，从分组、连加和平均分的概念题开始。
3. 点击“开始今日任务”。核心日课包括热身或到期复习、概念、变式、应用、提高和思维探索六个任务。
4. 读题、自己作答、查看解释，再明确点击继续。遇到困难可逐步查看提示，或打开“概念小实验”调整示例数字。
5. 完成核心课后可以结束。核心课固定六个任务；每日目标超过六题时，首页提供对应数量的自选口算加练，例如目标八题会提供两题加练。原目标保留，加练不影响核心课的完成与奖励。口算另有学习和熟练两种模式；错误反馈等待孩子主动操作，不自动跳题。

设置变更不会把正在做的半节课换成年级不同的新课。页面会分别显示当前课程范围与下一节课程的设置；刷新、返回首页和跨过午夜，也保留未完成课程。

分数题可用 `1/4` 这样的形式输入。带固定 `%` 标记的百分数输入框只填百分号前的数：填 `25` 表示 `25%`，填 `0.25` 表示 `0.25%`。

分组小实验可以轮流放一个物品，也可以按每组数量取出一组；支持键盘 Enter/空格、撤销最近一步和重新分配。调整数字或切换分配方式后从头操作，页面持续显示已分配与未分配的总量。这是理解方法的示例，答案仍由孩子在答题卡填写。

## 怎样提高难度

提高题和思维探索都有入门与进阶层级。推荐依据当前年级、单元和技能的有效首答记录；单纯刷新、切年级或看报告不会升级。初始规则要求至少八次首答、跨两次学习、至少两道不同题目或版本，首答正确率达到 80%，完整提示占比不超过 20%。明确薄弱的前置技能会限制进阶。

这是可调整的产品规则，不是提分承诺。有限题库会安排复习，并非每天都有六道从未见过的新题。家长报告区分首答正确、最终完成、独立完成和使用帮助；历史中无法还原的首答显示为未知。

## 换设备与离线

在家长报告页下载数据备份，在另一台设备打开数学侦探后选择备份文件，核对预览，再恢复。恢复前会保留当前设备的安全备份；两台设备各自使用本地记录，不会自动通过账号合并。未配置账号云同步。

联网时在家长页准备离线学习。核心缓存范围是首页、每日学习页和家长页及所需静态资源；准备成功后可继续缓存课程。未缓存页面首次离线无法打开，不能把此功能理解为所有页面均保证离线。应用更新会等待旧页面关闭，避免强行中断当前课程。

## 保存异常

如页面提示尚未保存，保留当前页面，恢复浏览器存储权限或可用空间后重试。不要用清除浏览器数据解决学习记录问题。损坏的原始存储不会用空白档案自动覆盖；优先使用已下载的备份恢复。

卸载浏览器、清理站点数据、更换浏览器和无痕窗口结束，都可能移除该设备的本地学习记录。跨设备或清理前先下载备份。

## 开发与回退

项目目录：`F:\CODEX\math-detective`。使用现有 Node.js 环境运行：

```powershell
npm run typecheck
$env:NEXT_BUILD_DIR = '.next-upgrade'
$env:NEXT_PUBLIC_APP_VERSION = '2.12.0'
npm run build
npx next start --hostname 127.0.0.1 --port 3212
```

升级前的工作区源码备份在 `reports/2026-09-28-upgrade/baseline/source.zip`，同目录含原始差异和哈希。回退时先保留当前源码和最新学习备份，再把源码备份解压到单独目录核对，避免覆盖原有未提交工作；旧版未必理解新版学习记录，不应直接用旧版写入唯一一份新版数据。
