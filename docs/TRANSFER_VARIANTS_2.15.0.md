# 一至六年级同构变式（2.15.0）

本次逐题处理原题库 G1–G6 的625道题。另有30道独立的奥数启蒙题，不计入这一分母。原题池仍为655道；变式使用独立ID，仅在原题完整讲解后进入迁移练习，不混入每日正常选题池。

最终覆盖数量、各年级分布和每一道未提供变式的原因，以本次发布目录的 `transfer-expansion-audit.json` 为准。开发中的候选数量不能替代发布验收数量。

每个变式都绑定具体原题内容、已知量、数量关系和所求未知量，重新编写题干、答案、算式、讲解、步骤和提示。普通数值变式必须改变数字和答案；数列、名次、图形性质等使用独立枚举或结构证明，改变实际约束或图形性质，不能只换人名、颜色和答案写法。

保持年级、知识点领域、所求目标、难度档、学期和输入类型。数值范围由具体变式决定，输入框的上限可以随正确数量调整；这不豁免对数字位数、进退位、整数与分数、单位换算、枚举规模及现实可行性的检查。原题中真实可见的无关背景也予以保留，避免把筛选信息题降成单纯计算。

独立数学核验使用精确有理数与有限穷举，不复用生成器的计算函数。同时使用实际输入数据和正式判题器逐项验证，避免出现“数学答案对，但输入后一直判错”的题目。日历、名次、余数、组合、面积最优化和统计数据分别检查其具体条件。

二年级乘除法入门单元遵守家长设置的已学口诀范围。需要背诵口诀的变式按新题的实际因数重新检查；等分和分组概念题不误判成口诀背诵。自动选择单元的课程使用实际课程设置快照识别单元，已学范围仍取家长当前设置。

完整讲解后的变式独立保存尝试、首次对错和完成状态。原题看过讲解后仍为待巩固；做对变式不能把原题改记为独立正确，也不会重复发放原题奖励或补回满分积分。刷新后继续同一个变式实例。

固定性质、固定拓扑或固定组合域中不能得到答案不同且难度等价的新题，以及原先隔离的5道不安全原题，明确记录原因。缺少生成实现或核验器不能作为已完成的不可用理由，也不能由宽松的旧匹配器绕过。

验收命令：

```text
npm run test:transfer-sources
npm run test:transfer-registry
npm run test:transfer-oracle
npm run audit:transfer-expansion -- --output reports/transfer-expansion-audit.json
npm run test:real-curriculum-generation
npm run validate:release
```

发布验收须包含全部静态和运行时检查、全量桌面/手机浏览器测试、同一Git提交的两条CI成功，以及Vercel候选部署和正式域名的真实浏览器复验。局部预检与HTTP成功响应不能代替这些证据。

原题库中发现的歧义、非唯一条件、单位精度和输入合同问题在源数据中修正，历史答题事件和积分不批量改写。基础原题ID不变，旧课程和备份仍可定位；变式ID采用 `transfer_<原题ID>_v1_01`。

两个过时的课程验证器改为调用现有实际课程生成路径，覆盖36个单元、28组设置与历史条件，共1008节课程、6048个题位；检查六题位职责、当前年级和单元、题目安全及去重、真实技能关系和未作答门槛。未继续以正则解析题库或旧版的跨年级预习分布判断当前课程。
