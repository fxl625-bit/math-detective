## P0 Bug 修复详情

### 根因
`grantDailyRewardOnce(state, completedLesson)` 在 `play/page.tsx` 的 `runLessonAction` 回调中捕获了 React hook 的 stale `state` 快照。函数返回 `{ state: updatedState, lesson: updatedLesson, bonusStars }` 中的 `updatedState.stars` 从未通过 `update()` 管道持久化 — 仅 `lesson.rewardClaimed: true` 被 `saveTodayLesson()` 保存，星星静默丢弃。

### 修复方案
```
grantDailyRewardOnce()
  → 返回 bonusStars: number（不再修改 state.stars）

addStars(bonusStars)   ← 新增 hook 方法
  → update((s) => { ...s, stars: s.stars + amount })
  → saveState() + notify()  ← 唯一正确的持久化路径
```

### 幂等保障
- `LessonStep.awardedAt` — 首次正确后写入 ISO 时间戳，刷新页面不重复发分
- `play/page.tsx` — 检查 `curStep.awardedAt != null` 跳过已发奖的步骤

## 新增功能：只读数据导出

**文件**：`lib/dataExport.ts`

**设计原则**：
- 所有 localStorage 读取通过 `JSON.parse(JSON.stringify())` 深拷贝，绝不修改原始数据
- 7 类数据：learningState / todayLesson / mistakes / rewards / avatar / settings / reports
- 32-bit hash checksum
- 文件名格式：`math-detective-backup-YYYYMMDD-HHmm.json`

**入口**：`/parent-report` 页面底部"数据备份与导出"面板，4 个按钮：
1. 导出完整 JSON 文件（触发浏览器下载）
2. 复制到剪贴板
3. 仅导出错题本
4. 导出学习报告摘要
