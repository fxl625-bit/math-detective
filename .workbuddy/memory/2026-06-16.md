# 2026-06-16 Math Detective v2.9.0 Adaptive Engine Fix

## Critical Bug Fix
- `loadState()` never initialized `learnerProfile` — entire v2.9.0 adaptive curriculum engine was dead code
- `getTodayLesson()` reused old lessons without version checking
- `buildDailyLesson()` had no `overrideState` parameter, making Node.js tests always use DEFAULT_GAME_STATE

## Root Cause Chain
1. `loadState()` initializes curriculumProfile and usageStage but NOT learnerProfile
2. `buildDailyLesson()` → `getUsageContext()` → `state.learnerProfile` = undefined
3. `slotPlan = learnerProfile ? generateDailySlotPlan(...) : null` → null
4. `selectCurriculumAwareQuestion()` → `if (learnerProfile && slotPlan)` → false
5. Falls back to legacy `selectQuestionForStep()` with random selection

## Fixes Applied
- `lib/storage.ts`: Added `buildLearnerProfile()` call in `loadState()` migration
- `lib/lessonPlanner.ts`: Version stamp, stale detection, step type degradation, dev diagnostics
- `__tests__/v290/test-real-lesson-generation.ts`: Real integration test (14 assertions)
- Total tests: 155 passing (93+28+20+14)
