## P0-6: 修复组件状态残留 ✅

### 根因
4 个页面组件中使用 `setTimeout(() => setState(...), delay)` 但未检查组件是否已卸载。
当用户在 setTimeout 触发前导航/切换阶段，会在已卸载组件上调用 setState，触发 React 警告并可能导致状态不一致。

### 修复文件
| 文件 | 修复内容 |
|------|---------|
| `app/play/page.tsx` | EquationAnswerPhase: 添加 `mountedRef`，setTimeout 内检查 |
| `app/play/solve/page.tsx` | FullSolvePage: 添加 useRef/useEffect，setTimeout 保护 |
| `app/play/clues/page.tsx` | FindCluesPage: 同上 |
| `app/play/noise/page.tsx` | NoiseReductionPage: 同上 |

修复模式：`const mountedRef = useRef(true); useEffect(() => () => { mountedRef.current = false; }, []);`
然后在 setTimeout 回调中 `if (mountedRef.current) setState(...);`

### 审记发现的低优先级问题（未修复）
- ~15 处交互按钮使用 `key={i}` 且 state 与 index 耦合（脆弱但当前功能正常）
- DetectiveMascot.tsx 中 onMessageEnd 依赖可能导致不必要重渲染
- 装饰性列表中的 index-as-key（可接受）
